# User Journeys

## Onboarding
Register -> authenticate -> create household -> invite partner -> partner accepts -> choose default split -> optionally register incomes -> dashboard empty state guides first transaction.

## Add expense
Enter amount/description/date -> choose payer -> mark household/individual -> choose category -> use default split or override -> choose cash/card/other -> optional installment -> confirm -> dashboard/analytics update.

## Understand imbalance
Open dashboard -> see paid percentage by member -> compare with planned responsibility -> expand explanation -> see top transactions/categories causing deviation -> optionally view compensation balance.

## Monthly household review
Review total income/spend -> fixed costs -> variable costs -> budgets -> installments ending -> unusual category changes -> goals -> suggested actions.

## Plan a purchase
Create purchase plan -> add estimated items/priorities -> mark purchased with actual price -> compare planned vs actual -> see remaining required amount.

## Manage recurring cost
Create recurring expense -> due/frequency/payer/split -> system projects commitments without infinite eager record creation -> mark/derive occurrences according to Stage 07 design.
